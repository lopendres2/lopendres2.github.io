# Telegram-бот магазина lopendres2

Бот принимает заявки из Telegram Mini App (сайт магазина) и пересылает их
администратору, а также умеет редактировать каталог `data/data.json`.

## Что исправлено в старом `bot.py`

| Было | Стало |
| --- | --- |
| библиотека `python-telegram-bot` v13 (`Updater`, `Filters`) — не работает на актуальных версиях | `Application` + `async/await` (PTB 21+) |
| `main()` объявлена дважды | один `main()`, все обработчики регистрируются до старта |
| `main()` вызывался до объявления `add_item`, поэтому команда `/add_item` не работала | команды регистрируются в `build_application()` |
| токен и ID «зашиты» в код | `.env` / переменные окружения, `.env` не попадает в git |
| любой текст считался данными Mini App | отдельные обработчики для Mini App, команд и обычного текста |
| `data.json` лежал в корне, путь был относительным | путь `data/data.json` рядом со скриптом, атомарная запись |
| нет проверки прав, нет логирования, нет `/start` | проверка админа, логи, `/start`, `/help`, `/myid`, `/catalog` |
| падение на отсутствующем `last_name` и битом JSON | безопасный разбор, HTML-экранирование, обработчик ошибок |

## Установка

```powershell
cd lopendres2.github.io
python -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env          # вписать BOT_TOKEN и ADMIN_IDS
python bot.py
```

Или просто запустить `run.bat` (Windows).

### Где взять значения

1. **BOT_TOKEN** — напишите `@BotFather` → `/newbot` → скопируйте токен.
2. **ADMIN_IDS** — запустите бота, отправьте ему `/myid`, полученный ID
   впишите в `.env` (можно несколько через запятую) и перезапустите бота.
3. **WEBAPP_URL** — адрес Mini App, по умолчанию
   `https://lopendres2.github.io/` (Telegram принимает только `https://`).

## Команды

| Команда | Кто | Что делает |
| --- | --- | --- |
| `/start` | все | приветствие и кнопка открытия каталога |
| `/catalog` | все | список товаров по категориям |
| `/myid` | все | показать свой Telegram ID |
| `/help` | все | справка |
| `/add_item категория \| название \| цена \| описание \| фото` | админ | добавить товар |
| `/del_item название` | админ | удалить товар |
| `/items` | админ | список товаров с номерами |
| `/reload` | админ | перечитать `data/data.json` |

Заявки из Mini App (`request_price`, корзина) приходят администратору
сообщением с именем покупателя, названием товара и ценой из каталога.

## Важно: каталог и сайт

Mini App берёт данные из
`https://raw.githubusercontent.com/lopendres2/lopendres2.github.io/main/data/data.json`,
а бот меняет **локальный** файл `data/data.json`. Чтобы изменения увидели
покупатели, файл нужно закоммитить и запушить:

```powershell
git add data/data.json
git commit -m "Update catalog"
git push
```

Кроме того, в текущем `data/data.json` у товаров нет поля `category`, а
страница категорий фильтрует именно по нему — поэтому каталог в Mini App
показывается пустым. Бот при добавлении товара это поле пишет; для старых
позиций его нужно добавить вручную (или прислать их боту заново).
